## About Me

I'm an engineer at **No Code Sage**, an AI-first enterprise engineering consultancy. I came into software from an unusual direction — a geology degree and zero CS background — and I'm learning the craft fast by building real production systems every day.

- Earlier in my software journey, but moving quickly and building in the open
- Working across a TypeScript monorepo: web apps, tooling, and developer workflow automation
- Big on doing things the correct, secure way rather than the quick way
